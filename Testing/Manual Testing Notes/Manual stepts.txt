
Manual Testing:
 -> testing performed completely with help of human.

Testcase:
 -> It is document which consist of instruction line procedure to verify functionality of 
an application.

Test scenarios:



steps of software manual testing:
  step-1: Analysis phase by going through SRS documents,guides, etc.
  step-2: creation of test plan touching all requirements.
  step-3: creation of test cases covering every requirements.
  step-4: execution of test cases covering test environment.
  step-5: analysis of test execution results,report discrepancies as defects.
  step-6: defect fix, and retesting. re-executing failed test cases

what kinds of Tests to Do manually?
   1.Exploratory testing: tester exploring application to find bugs that aren't easy
to detect through automated scripts. It relies human interaction.

   2.Usability testing: testers test ease of use,look and feel,overall user experience.

   3.Ad-hoc testing: Unplanned tests without any specific approach.  Testers randomly
 test different parts of application to find unexpected issues.

   4.User interface (UI) testing: check for visual elements, like layouts, fonts, and 
colours. 

   5.Accessibility testing: check if the application is usable by people with disabilities,
with accessibility standars.
