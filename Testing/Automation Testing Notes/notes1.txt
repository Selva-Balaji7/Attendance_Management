    Interface in selenium that allows automation of web applications by controlling web

what is Maven?: 
   ->A build automation tool used in java projects.
   ->used as a dependency management tool.
   ->uses xml language and its build script is(pom.xml)
   ->pom.xml contains all the dependencies needs for project
   ->maven reads pom.xml first and downloads the required dependencies into local repository.
   
what is Gradle?:
    ->build automation tool 
	->uses groovy or kotlin and its build script is (build.gradle/build.gradle.kts)
	->uses Gradle repositories
	
maven vs gradle:
            Maven                                 gradle
    1.slower due to full builds           Faster due to incremental builds
    2.Less flexible(strict convention)    More flexible(custom tasks,plugins)
